# 生财有术帖子标题生成（scys-title）

## 何时使用

用户要为生财有术（或类似知识星球/社群平台）发布帖子、文章、专栏时，基于内容生成吸睛标题。用户可能说"起个标题""帮我想几个名字""发布到生财"等。

## 命名规律（核心知识）

生爆款标题的核心公式：

**具体数字 + 结果/身份反差 + 方法论感 + 情绪钩子**

### 五大套路

1. **身份代入**：普通人 / 下班后 / 0 基础 / 打工人 / 宝妈——让读者第一眼对号入座
2. **量化结果**：月入 X 万 / 0 成本 / X 天跑通 / 年入几十万——数字越具体越可信
3. **交付感**：保姆级 / 一图看懂 / 全流程 / SOP / 清单 / 决策树——暗示拿走就能用
4. **反差式**：劝退 / 别再 / 我劝你 / 为什么你 X 还没 Y / 90% 的人死在 Z——制造认知冲突
5. **真实感**：复盘 / 亲测 / 跑通 / 踩坑 N 次后——降低广告感，提升可信度

### 组合技巧

- 纯方法论词（如"决策树""选型框架"）偏干，须搭配数字或身份词中和
- 冒号结构常见：`《钩子：交付内容说明》`，前半抓眼球，后半讲清楚是什么
- "盘了 X 篇文章/数据后" 式开头自带信息量背书
- 疑问式标题（"为什么你 X？"）直接戳痛点

## 工作流程

1. **读内容**：让用户提供或指路待命名的文档/内容；提炼核心要素：
   - 主题赛道（副业/AI/流量/电商…）
   - 关键数字（项目数/天数/收益/成本/数据量）
   - 目标读者身份（0 基础/程序员/宝妈/在职…）
   - 交付物形态（SOP/决策树/清单/复盘/工具）
   - 反差点或痛点（劝退点/常见误区/失败原因）
2. **按五大套路各出 1-2 个标题**，分组呈现：
   - 方法论主打型 / 数字冲击型 / 痛点劝退型 / 结果诱惑型（按内容可增删组）
3. **给推荐**：明确推荐 1-2 个并说理由（通常是"数据背书+信息量反差"或"痛点+悬念"）
4. **问变体**：询问是否需要往某方向多出变体

### 命名规则

- 用《》包裹标题
- 控制在 15-30 字为主体（生财列表页截断考虑）
- 数字用阿拉伯数字更抓眼
- 避免标题党空洞承诺（生财社区反感纯标题党，标题须有正文支撑）

## 示例

输入：28 个已验证副业项目 + 一棵决策树的选型文档

输出分组：
- **方法论主打**：《选副业别再瞎试了：一棵决策树帮你从 28 个已验证项目中锁定你的赛道》
- **数字冲击**：《盘了 4986 篇生财文章后，我把 28 个已验证项目画成了一棵决策树》
- **痛点劝退**：《别再问"做什么副业赚钱"了：先过这 7 道门，90% 的人死在 Q0》
- **结果诱惑**：《从 0 基础到年入几十万：28 条已验证路径，对号入座找到你的那条》

推荐：数字冲击型（数据背书+信息量反差）与痛点劝退型（悬念钩子）。
