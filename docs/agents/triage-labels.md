# Triage labels

Default vocabulary: each label string equals its canonical role name.

| Role | Label |
| --- | --- |
| needs-triage | `needs-triage` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

On the local markdown tracker these are recorded as the `Status:` line near the top of each issue file (e.g. `Status: ready-for-agent`).
