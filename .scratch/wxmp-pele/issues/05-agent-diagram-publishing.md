# 05: Agent 从 ASCII／文本说明完成整篇发布适配

**What to build:** 用户把一篇含 ASCII 图、说明性文本代码块、真实代码及各类引用的笔记交给 publish-to-wxmp，agent 能保留原意，将需要可视化的部分改写为 Mermaid，并沿用自动成图、上传、手机预览与用户确认流程完成发布适配。操作指南从当前手工预渲染 PNG 的方式切换到已集成的构建能力。

**Blocked by:** 03 — 同篇多图与各类内置图表可在手机上阅读；04 — 图表无法忠实呈现时阻止发布，并保留网址引用。
