# 03: 同篇多图与各类内置图表可在手机上阅读

**What to build:** 用户可在同一篇文章中混排多张、不同类型的 Mermaid 图表，保持独立内容与稳定资源引用；固定版本 Pele 的内置图表类型均走统一成图路径。发布后的中文标签与连线在手机阅读宽度下保持完整，而不是将整张宽图缩小到无法阅读。

**Blocked by:** 02 — 发布第一张离线渲染的中文 Mermaid 流程图。

**Status:** ready-for-human

- [ ] 在自包含文字与矢量形状的功能边界内开放固定版本 Pele 的全部内置图表类型，不维护额外类型白名单；外部 Mermaid 插件不在首版支持范围内。
- [ ] 代表性验收覆盖流程图、时序图、思维导图、状态图、类图、实体关系图及数据／时间类图表；期望布局按 Pele 的能力定义，不承诺与 Mermaid.js 像素级一致。
- [ ] 同篇多图的标识、资源名称、SVG 引用和样式相互隔离；相似内容、不同类型及相邻图表不会发生覆盖、串图或连线错引。
- [ ] 默认使用浅底深字的高对比样式与手机友好布局；在 375px 文章预览中验证代表性中文标签、长标签、节点与箭头无裁切或重叠，页面没有被图片撑宽。
- [ ] 布局调整保持节点、关系、箭头方向、条件和顺序不变。需要语义拆分才能阅读的密集图交由 agent 改写，CLI 不通过删减节点或关系来强行适配宽度。
- [ ] 每张图的 Mermaid、SVG 与 PNG 可追溯；修改其中一张图后重新构建、上传和预览，只有对应内容变化，其他图仍引用正确资源。
- [ ] 固定输入、字体、渲染配置与时间基准时，重复构建可稳定复用相同图像内容；对含隐式时间的图表明确记录其时间基准，避免把当前时间造成的变化误认为图表源码变化。
- [ ] 相同 PNG 沿用现有按内容去重的上传缓存；混排原有配图与多张生成图片时均能上传，并在模拟草稿正文中保留正确 CDN 地址。
- [ ] 多图、图表类型、中文与手机布局回归经真实 CLI 和浏览器预览验证，测试从 `npm test` 可达；正式支持的 macOS 与无桌面 Linux 使用随包字体，不依赖宿主字体回退。

## Comments

八种代表类型已在 375px/768px 验证 PNG 解码、文字边界和文字重叠，并逐图查看手机截图；多图与稳定重建通过。本机 macOS 验收完成，Linux 仍待 CI 实跑；截图与测试说明见 [验收记录](../verification.md)。
